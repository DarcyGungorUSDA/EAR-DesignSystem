# Welcome to the EAR Design System repository

This space exists to help our office create Word reports, PowerPoint presentations, Excel tables and figures, and (for some of us) code‑based outputs that all share a consistent look and feel. This repository has three types of things to support our shared visual identity.

## 1) Design documentation 

This space explains what a Design System is and why it's something lots of organizations have. It presents the EAR Design System and the rationale behind all design decisions. 

## 2) Microsoft Office templates

These are the files most staff will use.

## 3) Code

A subset of you work in R, SAS, or other tools that need EAR styling. This folder provides code so everyone can match the design system consistently.
